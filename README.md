# Data Analytics Portfolio

**Kumpulan proyek analisis data untuk mengeksplorasi data, menemukan pola, menghasilkan insight, dan mendukung pengambilan keputusan berbasis data.**

## Tentang Repositori

Selamat datang di **Data Analytics Portfolio**.

Repositori ini merupakan wadah kumpulan proyek analisis data yang saya kerjakan sebagai bagian dari proses belajar, pengembangan keterampilan, dan penerapan konsep data analytics pada berbagai studi kasus.

Setiap proyek memiliki fokus permasalahan, karakteristik data, serta pendekatan analisis yang berbeda. Melalui proyek-proyek ini, saya mengeksplorasi bagaimana data dapat diolah menjadi informasi yang lebih bermakna dan mudah dipahami.

Repositori ini akan terus berkembang seiring bertambahnya proyek dan keterampilan yang saya pelajari.

## Ruang Lingkup Analisis

Proyek-proyek dalam repositori ini mencakup beberapa bidang analisis data, antara lain:

- **Data Cleaning:** Memeriksa dan mempersiapkan data agar layak digunakan untuk analisis.
- **Exploratory Data Analysis (EDA):** Mengeksplorasi data untuk menemukan pola, tren, dan hubungan antarvariabel.
- **Business Analysis:** Mengidentifikasi permasalahan bisnis dan menjawab pertanyaan melalui data.
- **Data Visualization:** Menyajikan hasil analisis dalam bentuk tabel, grafik, dan dashboard.
- **Data-Driven Insights:** Menghasilkan temuan yang dapat menjadi bahan pertimbangan dalam pengambilan keputusan.

## Tools & Technologies

Beberapa perangkat dan teknologi yang digunakan dalam proyek-proyek ini:

- **SQL (MySQL):** Pengolahan, pembersihan, dan analisis data.
- **Microsoft Excel:** Pengolahan data, analisis, perhitungan, dan visualisasi.
- **Microsoft Power BI:** Pembuatan dashboard dan visualisasi data interaktif.

Penggunaan tools dapat berbeda pada setiap proyek, sesuai dengan kebutuhan dan pendekatan analisis yang digunakan.
